# Jiye Circle

二次元扩列社交平台，支持扩列广场、动态、聊天、VIP会员、积分系统。

## 功能特性

- 账号系统：邮箱/手机号注册登录，自定义头像和背景
- 扩列广场：资料卡展示，标签筛选，点赞互动
- 动态社区：发布文字动态，评论点赞
- 站内聊天：非实时消息，付费申请好友
- VIP会员：金色标识，内容置顶
- 积分系统：每日签到，积分兑换
- 管理员后台：用户管理，订单审核，举报处理

注册时使用 `admin@jiye.com` 自动获得管理员权限。

## 技术栈

- 纯前端 HTML/CSS/JavaScript
- Jsonbin 数据存储
- GitHub Pages 静态部署
- Android WebView APK 打包
